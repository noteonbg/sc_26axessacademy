⚛️ React Virtual DOM vs Direct DOM Manipulation:
Direct DOM manipulation like document.createElement() or element.appendChild() forces immediate browser reflow and repaint. React abstracts this via a Virtual DOM tree. When state changes, React computes minimal diffs and updates only the necessary real DOM nodes automatically!

# 🗄️ How to Access & Query H2 Database Console (`03-banking-jpa-demo`)

This guide explains how to open, log into, and query the **H2 In-Memory/File Database Console** for `03-banking-jpa-demo` and inspect JPA table generation (including the **Single-Table Employee** entity).

---

## 📌 1. Configuration Overview (`application.properties`)

The H2 Console is enabled in `src/main/resources/application.properties` with the following configuration:

```properties
# H2 File-Based Database Setup
spring.datasource.url=jdbc:h2:file:./data/bankingjpadb;AUTO_SERVER=TRUE
spring.datasource.driverClassName=org.h2.Driver
spring.datasource.username=sa
spring.datasource.password=
spring.h2.console.enabled=true
spring.h2.console.path=/h2-console
```

---

## 🚀 2. Step-by-Step Instructions: Opening H2 Console

### Step 1: Start the Application
Run the Spring Boot application on port `8083`:

```powershell
cd 03-banking-jpa-demo
mvn spring-boot:run
```

---

### Step 2: Open the H2 Console Login Page
Open your web browser and navigate to:
👉 **[http://localhost:8083/h2-console](http://localhost:8083/h2-console)**

---

### Step 3: Enter Login Credentials
On the H2 Console login screen, enter the exact connection parameters:

| Field Name | Value to Enter | Notes |
| :--- | :--- | :--- |
| **Driver Class** | `org.h2.Driver` | Standard H2 JDBC Driver |
| **JDBC URL** | `jdbc:h2:file:./data/bankingjpadb;AUTO_SERVER=TRUE` | **IMPORTANT**: Must match `application.properties` exactly! |
| **User Name** | `sa` | Default system administrator user |
| **Password** | *(leave blank)* | Password is empty by default |

Click **Test Connection** (should show *Test successful*), then click **Connect**.

### 📝 Sample SQL Queries for `EMPLOYEES` Table

Run these SQL queries in the SQL statement pane:

#### 1. View all seeded employees:
```sql
SELECT * FROM EMPLOYEES;
```

#### 2. Insert a new employee record:
```sql
INSERT INTO EMPLOYEES (name, email, department, salary, designation) 
VALUES ('Eve Adams', 'eve.adams@sc.com', 'Security', 88000.00, 'Security Engineer');
```

#### 3. Update an employee's salary:
```sql
UPDATE EMPLOYEES 
SET salary = 90000.00 
WHERE email = 'alice.johnson@sc.com';
```

#### 4. Delete an employee record:
```sql
DELETE FROM EMPLOYEES WHERE id = 3;
```

#### 5. Filter employees by department:
```sql
SELECT name, email, designation, salary 
FROM EMPLOYEES 
WHERE department = 'IT' 
ORDER BY salary DESC;
```

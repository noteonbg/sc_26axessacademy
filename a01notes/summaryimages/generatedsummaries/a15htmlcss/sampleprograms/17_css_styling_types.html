17. Three Types of CSS Styling Methods

1. External CSS (<link rel="stylesheet">)

Styled using external stylesheet (17_external_style.css).

This heading is also styled via external CSS.

2. Internal CSS (<style> in <head>)

Styled using internal CSS rules embedded inside head <style> tag.

3. Inline CSS (style="..." attribute)

Styled using Inline CSS attribute directly on the paragraph element.

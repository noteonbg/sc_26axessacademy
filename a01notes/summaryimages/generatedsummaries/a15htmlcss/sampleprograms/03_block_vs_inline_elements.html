03. Block-Level vs Inline Elements

1. Block-Level Elements

Block elements always start on a new line and stretch the full available width.

I am a Block-level <div> element.

I am a Block-level <p> paragraph element.

2. Inline Elements

Inline elements stay on the same line and take up only as much width as their content needs.

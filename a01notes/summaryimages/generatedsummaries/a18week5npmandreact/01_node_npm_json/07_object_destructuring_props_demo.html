Financial Domain: Object Destructuring vs React Props

This demo explains how destructuring JavaScript objects directly in a function signature is the exact mechanism React uses for Component Props.

1. JavaScript Function Signature Destructuring

// Function Signature Destructuring (Financial Account Statement)
function printAccountStatement({ accountHolder, accountNumber, balance, currency = "USD" }) {
    return `--- Account Statement ---
Account Holder : ${accountHolder}
Account Number : ${accountNumber}
Current Balance: ${currency} ${balance.toFixed(2)}`;
}

2. Direct Comparison: Plain JavaScript vs React Component

// Plain JS Function Call
printAccountStatement({
    accountHolder: "Euler",
    accountNumber: "ACC-789012",
    balance: 15450.75,
    currency: "USD"
});

// React Functional Component Call (Behind the scenes, JSX converts to identical JS object!)
<AccountCard 
    accountHolder="Euler" 
    accountNumber="ACC-789012" 
    balance={15450.75} 
    currency="USD" 
/>

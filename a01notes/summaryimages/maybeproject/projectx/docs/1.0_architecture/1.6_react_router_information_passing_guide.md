# 1.0 Beginner-Friendly React Router Information Passing Guide & Code Examples

## 2.0 Purpose & Introduction to React Routing
- **2.1** Purpose: Explain how data objects, resource IDs, and filter options are passed between React components during route navigation.
- **2.2** 3 Navigation Data Patterns:
  - Pattern 1: URL Path Parameters (`useParams()`) for mandatory resource IDs (`/products/:productId`).
  - Pattern 2: URL Query Parameters (`useSearchParams()`) for optional filters (`/catalog?category=hardware&page=2`).
  - Pattern 3: Route Location State (`useLocation()`) for passing transient data objects silently during `navigate('/checkout', { state })`.

## 3.0 Step 1: Central Route Definitions in `App.js`
- **3.1** Code Implementation Example:
```javascript
// Location: src/App.js
import React from 'react';
import { BrowserRouter, Routes, Route, Link } from 'react-router-dom';

// Importing feature page components via public API barriers
import { CatalogPage, ProductDetailPage } from './features/feature2_catalog';
import { CheckoutPage } from './features/feature4_checkout';

export default function App() {
  return (
    <BrowserRouter>
      <nav style={{ padding: '1rem', backgroundColor: '#1e293b', color: '#fff' }}>
        <Link to="/catalog?category=hardware" style={{ color: '#38bdf8', marginRight: '1rem' }}>🛒 Catalog (Query Params)</Link>
        <Link to="/products/101" style={{ color: '#38bdf8' }}>📦 Product #101 (Path Params)</Link>
      </nav>

      <Routes>
        {/* Route 1: Catalog Page accepting query parameters */}
        <Route path="/catalog" element={<CatalogPage />} />

        {/* Route 2: Product Detail Page accepting path parameter :productId */}
        <Route path="/products/:productId" element={<ProductDetailPage />} />

        {/* Route 3: Checkout Page accepting route location state object */}
        <Route path="/checkout" element={<CheckoutPage />} />
      </Routes>
    </BrowserRouter>
  );
}
```

## 4.0 Step 2: Query Parameters Example (`useSearchParams()`)
- **4.1** Scenario: User visits `/catalog?category=hardware&sort=asc`. Suresh (Developer 2) extracts query parameters to filter products.
- **4.2** Code Implementation Example:
```javascript
// Location: src/features/feature2_catalog/components/CatalogPage.js
import React from 'react';
import { useSearchParams, useNavigate } from 'react-router-dom';

export function CatalogPage() {
  // 1. Hook to read and update URL Query Parameters
  const [searchParams, setSearchParams] = useSearchParams();
  const navigate = useNavigate();

  // Extract query parameters with fallback defaults
  const activeCategory = searchParams.get('category') || 'all';
  const activeSort = searchParams.get('sort') || 'asc';

  return (
    <div style={{ padding: '1.5rem', backgroundColor: '#f0fdf4' }}>
      <h2>🛍️ Suresh Catalog Page (Query Parameters)</h2>
      <p>Active URL Query Category: <strong>{activeCategory}</strong> | Sort: <strong>{activeSort}</strong></p>

      {/* Buttons updating URL Query Parameters dynamically */}
      <button onClick={() => setSearchParams({ category: 'hardware', sort: 'asc' })}>
        Filter Hardware
      </button>
      <button onClick={() => setSearchParams({ category: 'software', sort: 'desc' })} style={{ marginLeft: '0.5rem' }}>
        Filter Software
      </button>

      <div style={{ marginTop: '1rem' }}>
        <button onClick={() => navigate('/products/101')}>
          View Product #101 Details (Path Param Navigation)
        </button>
      </div>
    </div>
  );
}
```

## 5.0 Step 3: Path Parameters Example (`useParams()`)
- **5.1** Scenario: User visits `/products/101`. Suresh extracts `:productId` from the URL path to load item details.
- **5.2** Code Implementation Example:
```javascript
// Location: src/features/feature2_catalog/components/ProductDetailPage.js
import React from 'react';
import { useParams, useNavigate } from 'react-router-dom';

export function ProductDetailPage() {
  // 1. Hook to extract URL Path Parameters defined as /products/:productId in App.js
  const { productId } = useParams();
  const navigate = useNavigate();

  // Simulated product object fetched using productId
  const productData = {
    id: productId,
    name: `Enterprise Cloud Node #${productId}`,
    price: 299,
    description: 'High-performance cloud node server.',
  };

  const handleProceedToCheckout = () => {
    // 2. Programmatic Navigation passing transient data object via Route State
    const orderPayload = {
      product: productData,
      quantity: 1,
      totalAmount: 299,
      purchasedAt: new Date().toLocaleTimeString(),
    };

    navigate('/checkout', { state: { orderSummary: orderPayload } });
  };

  return (
    <div style={{ padding: '1.5rem', backgroundColor: '#fff7ed' }}>
      <h2>📦 Product Detail Page (Path Parameter)</h2>
      <p>Extracted Path Parameter (productId): <strong>{productId}</strong></p>

      <div style={{ backgroundColor: '#fff', padding: '1rem', borderRadius: '6px', border: '1px solid #fed7aa' }}>
        <h3>{productData.name}</h3>
        <p>Price: ${productData.price}</p>
        <button onClick={handleProceedToCheckout} style={{ backgroundColor: '#ea580c', color: '#fff', padding: '0.5rem 1rem', border: 'none', borderRadius: '4px', cursor: 'pointer' }}>
          💳 Proceed to Checkout (Pass Route State Object)
        </button>
      </div>
    </div>
  );
}
```

## 6.0 Step 4: Route Location State Example (`useLocation()`)
- **6.1** Scenario: Developer 4 (Checkout) receives the order payload object passed from Suresh's Product Detail Page during navigation.
- **6.2** Code Implementation Example:
```javascript
// Location: src/features/feature4_checkout/components/CheckoutPage.js
import React from 'react';
import { useLocation, useNavigate } from 'react-router-dom';

export function CheckoutPage() {
  // 1. Hook to access current location state object passed during navigate()
  const location = useLocation();
  const navigate = useNavigate();

  // Extract route state with safety fallback check
  const orderSummary = location.state?.orderSummary;

  return (
    <div style={{ padding: '1.5rem', backgroundColor: '#faf5ff' }}>
      <h2>💳 Developer 4 Checkout Page (Route Location State)</h2>

      {orderSummary ? (
        <div style={{ backgroundColor: '#fff', padding: '1rem', borderRadius: '6px', border: '1px solid #e9d5ff' }}>
          <p style={{ color: '#166534' }}>✅ <strong>Received Route State Object from Suresh Component:</strong></p>
          <p>Product: <strong>{orderSummary.product.name}</strong></p>
          <p>Total Amount: <strong>${orderSummary.totalAmount}</strong></p>
          <p>Time: {orderSummary.purchasedAt}</p>
        </div>
      ) : (
        <div style={{ color: '#991b1b', backgroundColor: '#fee2e2', padding: '1rem', borderRadius: '6px' }}>
          <p>⚠️ No route state object found. User accessed `/checkout` directly without selecting a product.</p>
          <button onClick={() => navigate('/catalog')}>Return to Catalog</button>
        </div>
      )}
    </div>
  );
}
```

## 7.0 Summary Matrix for Beginners
- **7.1** `useParams()`: Use when information MUST be visible in the URL path (e.g. `/users/42`).
- **7.2** `useSearchParams()`: Use when information is optional or filter-based (e.g. `?search=react&sort=desc`).
- **7.3** `useLocation()`: Use when passing complex data objects between screens without showing details in the URL.

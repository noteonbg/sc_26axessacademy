# 1.0 Developer Onboarding & Environment Setup Guide

## 2.0 Prerequisites & Installation
2.1 Node.js Runtime Requirement: Node.js version 18.0.0 or higher.
2.2 Package Manager Requirement: npm version 9.0.0 or higher.
2.3 Code Editor Requirement: Visual Studio Code with ESLint extension enabled.

## 3.0 Step-by-Step Local Environment Setup
3.1 Step 1: Open workspace terminal in UI layer directory `projectx/ui/`.
3.2 Step 2: Execute command `npm install` to install all dependencies.
3.3 Step 3: Execute command `npm start` to start Create React App local development web server.
3.4 Step 4: Open web browser and navigate to `http://localhost:3000`.

## 4.0 Developer Workflow & Git Branching Alignment
4.1 Git Strategy Reference: Review `docs/5.0_onboarding/5.2_git_branching_strategy.md` for full-stack monorepo branching rules.
4.2 Phase 1 UI Branching Rule: Create branch `feature/ui-dev<N>-<feature-name>` from `develop-ui`.
4.3 Phase 2 Backend Branching Rule: Create branch `feature/backend-dev<N>-<feature-name>` from `develop-backend`.
4.4 Daily Commit Guidelines: Commit changes frequently to your isolated feature folder `src/features/feature<N>/`.
4.5 Pull Request Protocol: Create Pull Request targeting `develop-ui` or `develop-backend` with mandatory review approval from Developer 6 (Lead Integrator).

# 1.0 Developer Onboarding & Environment Setup Guide

## 2.0 Prerequisites & Installation
2.1 Node.js Runtime Requirement: Node.js version 18.0.0 or higher.
2.2 Package Manager Requirement: npm version 9.0.0 or higher.
2.3 Code Editor Requirement: Visual Studio Code with ESLint extension enabled.

## 3.0 Step-by-Step Local Environment Setup
3.1 Step 1: Open workspace terminal in repository root directory `react-multi-dev-app/`.
3.2 Step 2: Execute command `npm install` to install all dependencies.
3.3 Step 3: Execute command `npm start` (or `npm run dev`) to start local development web server.
3.4 Step 4: Open web browser and navigate to `http://localhost:3000` (or `http://localhost:5173`).

## 4.0 Developer Workflow & Git Feature Branching Protocol
4.1 Git Branch Naming Rule: `feature/f<1-6>-<short_description>` (e.g., `feature/f1-auth-login`).
4.2 Daily Commit Guidelines: Commit changes frequently to your isolated feature slice folder `src/features/feature<N>/`.
4.3 Pull Request Protocol: Create Pull Request targeting `main` branch with 1 peer review approval from Tech Lead before merging.
